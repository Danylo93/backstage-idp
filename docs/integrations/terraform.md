# Terraform Readiness

## Objetivo

Terraform segue como trilha futura da plataforma, mas o template dedicado nao esta habilitado nesta fase.

## Caminho de evolucao

1. Reintroduzir um template dedicado quando o fluxo de IaC entrar no escopo imediato.
2. Definir strategy de state remoto em `azurerm`.
3. Registrar os modulos gerados como `Component` ou `Resource` no Catalog.
